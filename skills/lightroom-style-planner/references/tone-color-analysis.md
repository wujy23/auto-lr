# 从画面关系到调整假设

用于分析参考图、待修图并制定目标。此处方法是依据文末素材形成的项目工作法，不是教材原文，也不是经过标定的 LR 参数反演算法。参考图提供可迁移的关系；最终数值由当前照片、已有显影状态和实际渲染共同决定。

## 1. 先建立可比的观察

- 查看待修图的当前 LR 预览与设置。区分原始文件、当前显影结果、参考成片，不把 RAW 文件直接解码的外观当成 LR 当前外观。
- 记录影响比较的配置文件、处理版本、白平衡、SDR/HDR、裁切及预览色彩空间等已知信息。前后预览尽量使用相同导出和显示条件；参考图条件未知时降低量化比较的可信度。
- 选有意义的对象和区域比较，如主体/背景、前景/远景、受光面/背光面。两图题材不同，优先比较视觉角色，不匹配整幅直方图或所有颜色比例。
- 区分 `observed`（看见的关系）、`inferred`（可能成因）、`proposed`（本轮建议）。没有采样就写视觉估计；参考 JPEG 无法唯一确定作者的灯光、蒙版和滑块数值。

## 2. 影调：分开判断四件事

| 判断 | 观察的问题 | 对方案的影响 |
|---|---|---|
| 整体明暗分布 | 亮、中、暗区域各占多大面积，视觉重点落在哪里？ | 高调不等于过曝，低调不等于全图减曝光；先判断是否需要整体移动 |
| 黑白端与跨度 | 哪些位置是真正深黑和亮端？重要纹理是否截断？ | 深黑可与可读暗部共存，不强求直方图铺满，也不强求每个暗角都有细节 |
| 区域之间的分离 | 主体相对背景、前景相对远景有何明暗差、反差差？ | 主体与背景同样明亮时，整体增曝光可能不能解决分离；先选择哪一方应变 |
| 区域内部的层次 | 单个对象的明暗面、细节反差和过渡是否合适？ | 对象提亮不等于体积增强；远山内部反差须对照目标：过强可能损失距离感，过弱也可能让山体被灰底吞没 |

直方图能提示分布与截断，不能告诉你哪个物体需要改变。先确定观看顺序和空间关系，再考虑细节可读性；避免为了“细节丰富”把所有区域拉到相近明度。

## 3. 色彩：先确定颜色在画面中的作用

为重要色区记录对象、位置、面积、色相倾向、明度、彩度与视觉角色。角色可为环境主色、视觉重点色、辅助色；不要求每张图必须恰好三色，也不把面积最大者自动当作主体。

- **关系优先**：主体颜色显得弱，可能是环境过亮或过浓。比较“加强主体”和“收敛环境”哪个更符合保护项，不默认给主体加饱和度。
- **色相与明度分开描述**：蓝天的问题可能是太暗、太浓或偏青，不用一个“蓝色太重”同时驱动三个方向。
- **保留辅助信息**：统一色调不等于抹掉所有辅助色。颜色承担材质识别、光源提示或空间分层时应保留差异。
- **中性有条件**：云、灰墙、皮肤与木材可以是保护对象，但受暖光的白物体不必修成中性。保护真实光色与不受欢迎的偏色需分开判断。
- **冷暖看邻域**：同一个色块在不同背景下会有不同感受，既看局部采样，也看周围颜色。避免把蓝、红等色相固定解释成某种情绪。

## 4. 写成可以验证的问题，再选择控制范围

每个关键问题用一条短记录串联：

`证据 → 目标关系 → 优先级 → 范围 → 主要控制 → 初值依据 → 预期变化 → 保护项/副作用 → 验收方式`

优先解决影响观看顺序、空间或目标风格的少数差异，其他差异可以保留。主控制由问题范围决定，以下仅为条件示例：

| 已识别问题 | 候选主要控制 | 先排除的误用 |
|---|---|---|
| 主要区域普遍比目标暗，亮端仍有余量 | 全局曝光；结合当前设置估计绝对目标值 | 仅一个对象偏暗却全局提亮 |
| 中间调分离不足，黑白端已合适 | 主曲线相应段或对比度，指定主要承担者 | 同时大幅推对比、压黑和 S 曲线 |
| 画面中相关绿色均过于抢眼 | HSL 对应色区；核对黄绿过渡 | 未检查同色主体便全局降绿 |
| 只有环境草地需收敛，主体同色需保留 | 区域蒙版及实际支持的局部颜色控制 | 把全局 HSL 当作精确对象选区 |
| 远山过硬而前景已合适 | 适用的局部反差/去朦胧控制与柔和过渡 | 全图去雾、清晰度与饱和度一起提高 |
| 需要改变暗亮部冷暖关系 | 现有色彩分级或通道曲线中合适的主要控制 | 按“电影感”固定给所有阴影染青 |

全局与蒙版在同一方案中设计：先判断哪些区域应一起变，哪些应分开，再分配修正量。不把蒙版固定当作最后补救，也不让全局和局部各承担完整修正。颜色与影调会相互影响，RGB 曲线、去朦胧等变化后需一起检查明度和彩度。

## 5. 初值是待验证的假设

依据优先级：用户指定准确值；同图或处理条件确实可比的历史渲染响应；当前值、视觉差异和保护边界支持的估计。历史响应也不能保证可跨相机、配置文件、光线或题材线性迁移。

没有标定时选择有依据、便于纠偏的初值，明确低置信判断；不凭“彩度降低百分之几”计算 HSL 点数，不把预览编码亮度比例当作曝光差。执行仍须输出合法的最终绝对值，估计的不确定性不能变成缺字段的执行计划。

默认合并执行并查看一次结果，仅对明确未达目标的关系集中纠偏，遵守主流程最多两轮纠偏的限制。保留旧值、目标值、渲染结果与判断，使以后有可用的本项目经验。

只有一个重要判断确实无法通过当前信息取舍、且额外渲染有价值时，才考虑少量候选比较。需已核实可从同一基线独立生成、隔离并可靠恢复；快照存在本身不证明接口能自动恢复。当前入口未确认这些能力时沿用普通闭环，不假设可以自动分支。候选不能成为绕过轮数限制的无限搜索，也不为每个滑块试多个值。

## 6. 条件示例：以实际差距决定方向

以下是假设场景，不是对某张真实照片的分析或测量。若实际远景比参考更灰、更缺少明暗分离，应反向考虑改善区域反差；不能机械套用本节“远山过硬”的场景。

参考图：暖色小屋先被看见，环境绿较克制，远山内部反差低。待修图：小屋颜色已自然，草地亮且饱和，远山纹理很硬，天空亮度合适。

- **关系目标**：小屋优先于草地；远山比近景柔和；天空仍保持当前亮度。不能仅由此推出全图降曝光或白平衡变冷。
- **联合设计**：先判断草地与其他绿色是否同向需要收敛。同向可选 HSL；若同色主体需保护，则需区域控制。远山单独处理内部反差，前景与天空列为保护项。小屋可以不改。
- **执行约束**：若远山穿插树枝，需要精确排除天空与树枝，而现有连接只能创建线性/径向渐变，就要判断几何软过渡是否足够；不够时记录能力缺口，不能把椭圆命名为“远山对象”就声称解决。
- **结果判断**：缩略观看是否先看到小屋、近远是否更清楚；放大看山脊是否有光晕、草地是否失去材质。草地彩度下降但小屋仍不突出，应重查草地明度和竞争亮点，而非自动继续降饱和。

## 7. 素材依据与阅读边界

- [Thomas：摄影后期调色漫谈](https://chuweimin.com/tutorials/a/color-grading-mood/)：阅读文章正文，借鉴主色、视觉重点与辅助色，以及面积、明度、饱和度共同影响画面的分析；未将色相与情绪的对应当作定律。
- [Albers Foundation：Interaction of Color](https://www.albersfoundation.org/alberses/teaching/interaction-of-color) 与 [One Color Becomes Two](https://www.albersfoundation.org/learning/workshops/one-color-becomes-two)：阅读基金会说明及练习，借鉴颜色依赖邻域、通过比较观察的原则；并非通读《Interaction of Color》全书。
- [Bruce Barnbaum：Finding Your Groove](https://rockynook.com/article/finding-your-groove/)：阅读出版社公开节选，借鉴观察形、线、影调、颜色与空间关系的思路；不声称通读作者摄影教材。
- [Adobe：Image tone and color](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/image-tone-color.html)、[Color Mixer](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/color-mixer.html) 和 [Masking](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/masking.html)：工具作用与选区类型的官方依据；实际字段和能力以当前连接为准。
- [Jeff Schewe：The Digital Negative，第二版](https://www.peachpit.com/store/digital-negative-raw-image-processing-in-lightroom-9780134033419)：查阅出版社目录和公开样章，目录可供后续按问题学习；未读到的影调章节不作为本规范具体结论的证据。

关系分析表、优先级、参数假设、能力检查和验收记录是本项目综合设计；素材没有证明这套自动化流程已经提高成片质量，仍需真实照片验证。未观看的视频不作为已学习的依据。
