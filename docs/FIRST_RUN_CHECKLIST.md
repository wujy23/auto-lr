# 首次使用验收记录

用途：在另一台 Mac 或干净用户环境验证实际下载体验。当前尚未完成这项实机验收；离线测试不能代替它。

记录项目 VERSION、macOS、芯片、Python、Codex 应用及 CLI、Lightroom Classic 版本。不要记录密码或令牌。

1. 从将要分发的 ZIP 解压到带中文或空格的固定目录，确认不含作者照片、历史任务和本机安装配置。
2. 在 Codex GUI 打开该目录，确认发现两个项目技能；发送 README 的安装请求。
3. 记录缺 Python、未登录、插件尚未安装等初始状态是否得到可操作提示。
4. 检查 setup 目标路径和安装回执，第二次 setup 应无重复安装。只保留一份启用的插件。
5. 在 Lightroom 加载并 Start connection；doctor 全部通过。
6. 在同一个 GUI 宿主运行 `doctor --smoke-model`，确认模型可调用。
7. 使用用户明确授权的一张测试照片副本和一张参考图，走公开 `harness.py run`。记录调用 ID、run 目录、最终状态以及实际导出或预览位置。开发测试通过不授权自动执行这一步。
8. 正式导出仅在 `complete` 且导出文件存在时确认；`limit_reached` 应正常退出并保留预览，不报告成片已通过。
9. 停止连接后，按 ZIP 更新指南更新一次；确认个人素材保留、插件重载后连接到原固定目录。

## 本轮本机验证范围

- Python 行为测试、模拟 Lightroom/Codex 调用。
- 有 Adobe Lua 运行库时执行模拟 SDK 测试；没有该运行库的 CI 会跳过对应项。
- 发行包解压到干净目录后的离线测试、公开入口帮助和空素材库查询。
- 离线开发验证不处理真实照片，不代表另一台 Mac 已验证。
